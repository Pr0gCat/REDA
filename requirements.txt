# Python dependencies for REDA's Verilog frontend (src/frontend/).
#
# `synthesize_verilog` shells out to Yosys via `yowasp-yosys` -- a WASM build
# of Yosys 0.68 with ABC built in -- to parse and optimise Verilog. It stops
# at the gate level (Yosys's own $_AND_/$_NAND_/$_MUX_ cells); REDA's own
# frontend (src/frontend/yosys_json.rs) reads that into a Netlist, and
# src/compile/lowering.rs -- not ABC -- decides how each gate becomes
# redstone. See src/frontend/mod.rs's module doc comment.
#
# This is the only part of the crate that needs Python at all -- the rest of
# the build, and every test outside tests/verilog_frontend.rs, has no
# dependency on it. `conformance/`'s own Python scripts are unrelated to this
# file and manage their own environment.
yowasp-yosys>=0.68
