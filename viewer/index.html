Topology

Primitives

Redstone dust -- a connection is a material, not an arrow, and it ends on the block that reads it: an unbroken run from one primitive to the next, never stopping at a boundary in between. Solid, because a broken line reads as a broken connection -- and because this graph has no positions, so a run has no length and no known signal loss, and a solid line offers nothing to count. A wire merge -- no torch, no support, no gate body: the point where several branches' dust are allowed to touch. Dotted spokes reach the nodes whose dust joins there. A spoke is a hairline, not a run of dust: it says those runs are one net, it is not another run beside them. A shared torch -- most expansions start by inverting an input, so !x is built once and reused. It sits in the hull of the cell that built it, ringed in violet, and the cells that read it without owning it hold fewer primitives than their recipe has steps. The edges to those cells are ordinary dust, because that is what they are; the ring is the credit.

Cells

A hull is a label, not a container. It wraps the primitives that are one gate-level cell -- and, nand, mux, andnot, ... -- and is named with its kind, in the same spelling src/circuits/baked/*.netlist uses. No signal enters or leaves it; edges cross its outline without noticing. Each cell gets its own hue so that two overlapping hulls read as two. What a cell costs is something you count rather than decode: a nor is one torch, an and is three. A merge that lowers into no primitive at all is hulled around its own junction ring -- the one thing it does have. Zoomed in, every primitive carries its #id and every incoming edge carries the index of the cell input that lands there, in the cell's own declared pin order -- andnot (A & !B) and mux (S ? B : A) are not symmetric, so which signal reaches which torch is part of what the circuit is. Hover any primitive for the same thing in words.

Gates

NORn -- a torch on its support. One badge around the single node the gate expands into; each gate gets its own hue. ORn wire merge -- no torch, no support, no body: a dust junction where several branches meet. Dotted hairline spokes reach the nodes whose dust actually joins there.

Edges

Redstone dust -- producer to consumer, drawn as the material that carries it rather than as an arrow, and ending on the node that reads it. Solid and unbroken: the graph has no positions, so a run has no length and no known signal loss, and there is nothing here to count. How it is finally realised (a dust path, adjacency, or otherwise) is not decided at this layer.
