# 可交換閘接腳指派實驗

基準 `f827027`，有效生成器仍為 `0de792e`。上一輪確認 g1 → g25／g17 的長線路中繼器為主要延遲來源；固定原閘位置交換輸入有縮短水平距離的空間。本輪實際建立通用接腳指派原型，未辨識案例名稱。

## 實驗方法

先正常編譯取得來源位置，再對獨立 lowered netlist 的可交換 NOR／Merge 輸入列舉 2／3 輸入全部排列，按最長水平距離、水平總距離選擇嚴格較好的排列。固定 tie 順序，記錄每個實體 port 對應原邏輯 input 的排列，再以改排後的 netlist 重新完整編譯及驗證。未修改原前端產物、來源對應或公開輸出映射；DFF 等有不同接腳角色的閘不交換。Unified3d 種類不套用 channel 位置估算。

這是測試端的實驗性等價網表轉換，並非已完成的正式 emitter 接腳對應 API。重新編譯可能連帶改變拓樸排序、布局、共用 tracks、路由與 fallback，所以不能把結果解讀為只有一條原線路縮短的局部效果。

先測全部 2／3 輸入閘，再分離只交換兩輸入閘、只交換兩輸入 NOR，最後增加每個原邏輯輸入的水平距離皆不得變長的條件。

## 結論與還原

最小化局部水平距離沒有控制不同分支的相對到達時間。即使每個輸入的水平距離皆不變長，仍可增加單一輸入毛刺。不能用這項幾何分數直接作為電路品質驗收或接受規則。下一個定位方向應包含切換路徑的實際事件到達與分支交接，不只最慢線路長度。

所有原型已撤回，原品質、矩陣與見證測試還原，沒有修改生成器或固定驗收基準。相鄰 JSON 保存原型程式、各候選實體到邏輯接腳排列及門檻失敗前的量測摘要。原始日誌為本次環境 /tmp/reda-pin-experiment.log、/tmp/reda-pin-two-experiment.log、/tmp/reda-pin-nor-two-experiment.log、/tmp/reda-pin-no-longer-experiment.log。

還原後主要品質、額外形狀及兩套路徑見證全部通過，四個主要產物的完整指紋、最慢及平均時間、毛刺計數再次與已提交生成器的獨立證據比對一致。
