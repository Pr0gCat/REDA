# Native integral parameter declarations and hierarchy

Concrete added support: `parameter`/`localparam` inferred sized two-state values and explicit `logic`/`wire`/`reg`, packed descending `[N-1:0]`, `int`/`integer`, and `signed`/`unsigned` modifiers. Packed parameter widths are 1..64. Explicit sized values support all four existing radices, including signed `N'sb/o/d/h` spellings in constant expressions. A parameter's normalized value owns width and signedness. Comma declarations inherit the declared type; a new `parameter`/`localparam` resets that inheritance.

Declaration and instance override boundaries use the formal parameter type: truncation discards high bits; extension follows the source value's signedness before adopting the declaration's signedness. Named and positional overrides normalize in the child scope before dependent values/ranges. Identifier references and bit/part selections consume the normalized width and value, not a globally assumed 32-bit word. Constant add/subtract/multiply use common maximum operand width, signed only when both operands are signed, and modular fixed-width results. A mixed unsigned expression zero-extends operands. Multiplication wraps its host intermediate before masking, including the 64-bit all-ones product. Legacy unsized integer expressions retain their existing checked signed-32-bit overflow contract and minimum-literal behavior.

This is an explicitly bounded integral subset, not full SystemVerilog: additional packed dimensions on integer types, ascending/nonzero-based packed ranges, parameter values wider than 64, nonintegral/type parameters, general constant functions/operators, and unsized positive values outside the historical i32 subset remain unsupported or invalid. Signed literals in ordinary data expressions remain explicitly unsupported; parameter identifiers supply normalized bit vectors to the existing equal-width data-expression subset. No general sign-extending data assignment or four-state/Z resolution is introduced. Top-level inout is still incomplete. These restrictions do not complete gap 5 or any of the eight broad goals.
