# Synchronous reset statements and conditional next state

The native parser previously rejected every clocked `else` and represented only one enable assignment. It now represents recursive clocked conditional branches, including `else if`, optional single-statement `begin/end`, and the usual nearest-unmatched-if binding for dangling `else`. Each conditional tree selects the next value of one register slice. Elaboration validates every branch target and width, lowers the tree through the existing RTL mux, and reads the existing register identity for missing branches. Explicit branch joins and implicit hold muxes retain distinct debug origins. Complete conditional source spans include their closing block tokens.

This extends the responsible source layers without adding a physical reset primitive, simulator behavior, verifier exception, clock stage or wait. Synchronous reset acts only on the declared clock edge. Reset and other data-control changes during low/high hold phases cannot update Q. Legacy `always` and both clock polarities use the same path; hierarchy keeps its existing clock aliases. Async event lists, multiple register targets or writes within one block, combinational conditional statements and data arithmetic remain outside this implementation. Rejection is not counted as support for those features.

Source tests use an independent literal edge oracle over reset priority, enable, data and hold. They cover rising/falling edges, legacy/SystemVerilog forms, block branches, explicit and implicit holds, dangling-else binding, deterministic netlists/debug data, and branch-join provenance. Negative checks retain target, slice, width and nonblocking requirements. The previous `else` rejection check now verifies accepted behavior; its existing feedback checks remain. Statement counter/FSM/state-enable netlists exactly equal their existing expression-form controls.
