# Native integer parameter defaults

The native frontend now resolves module-header and body `parameter` / `localparam` defaults before signal widths. It supports untyped decimal integers and `int` / `integer`, dependent and forward references, unary signs, parentheses, addition, subtraction and multiplication. Constant expressions work in packed widths and read/write selectors. Parameter data references become 32-bit two’s-complement constants, including bit and part selections. Definitions remain scoped to the selected module.

Checked signed 32-bit evaluation rejects overflow as Unsupported; auto mode can use Yosys. Unknown names, cycles, duplicates, namespace collisions, parameter writes and invalid widths are source errors. Existing descending zero-based ranges, maximum width 4096, writable-target and per-bit driver checks remain. Packed or sized parameters, type modifiers, constant functions and other constant operators, instance overrides, instances and inout remain incomplete. The literal spelling `-2147483648` is outside this subset; `-2147483647-1` is representable. This is not complete SystemVerilog integer semantics.
