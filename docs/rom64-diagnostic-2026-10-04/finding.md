# ROM64 paired diagnostic finding

This is a fixed diagnostic sample, not production adoption or a replacement for the full 8,192-phase controls. The same source-bound executable generates both worlds and measures the same continuous history: addresses [0,21,42,63] crossed with those four addresses, each setup then target, 32 phases, starting at address zero without resetting the simulator. The matrix admission and existing 10,000,000 proof budget are explicit and isolated. Production admission remains four/five inputs.

Independent evaluation matches all 64 literal ROM words against both source and implementation Boolean graphs. Every public event and every implemented-gate event in the 32 recorded phases replays to the independently expected final state. The control has 603 observed gates and 5,036 extra internal transitions; the matrix has 2,208 observed gates and zero extra internal transitions. These observations do not cover every physical site and do not prove the full protocol.

Worst settlement is 646 versus 56 game ticks. Control driver/lamp glitches are 183/177 across setup and target; the matrix has zero. There are no sample quality-component regressions, no per-phase settlement regressions, and no per-phase/channel arrival regressions. Block counts are not acceptance criteria. Runtime observations are diagnostic, not controlled general benchmarks.

Both retained worlds independently reload to canonical fingerprints 90ad27236b013529f500c04347b760a04e08851abd88a1ee9c657ae9eaafaa37 and f3af4444f9776335f3c51a768a8a7ae3d5e387e66974807feb5009919b459b5a. The probe, fixture and executable hashes were reverified against source-binding.json. The complete diagnostic source and exact Python helper sources are archived. Corruption checks reject an unknown internal event and a changed literal ROM word.

To reproduce the audit, extract diagnostic-source.tar.gz into a temporary directory. Create wave-control-bound-output and wave-matrix-output there, and decompress control-result.jsonl.gz and matrix-result.jsonl.gz into their respective result.jsonl files. With the archived helper tools on PYTHONPATH, run python3 audit.py TEMP_DIRECTORY. Run python3 check_rejection.py TEMP_DIRECTORY from this repository for the two corruption checks. Replaying retained events does not rerun generation or qualify six-input default selection. Complete original-controlled waveforms and the actual-default repeats remain required.
