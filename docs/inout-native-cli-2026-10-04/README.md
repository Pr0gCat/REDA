# Default native/auto CLI shared-inout prototype

The isolated build_circuit binary now structurally recognizes a parsed top-level Inout port and routes `verilog <file> <top>` with native or auto through the source-to-physical shared-channel compiler. It exports the actual litematic world plus source-owned typed shared-inout sidecar. Ordinary sources and explicit Yosys mode retain their original path. An unsuccessful preliminary parse defers to the existing selector, which retains ownership of diagnostics and optional fallback. Physical errors never trigger Yosys retry.

The actual CLI runs with empty PATH and REDA_PYTHON=/nonexistent/reda-python in both native and auto modes. Both return0 and produce the retained bundles. An independent external-crate test compiles the same original source through the native physical entry and loads each CLI-exported bundle against the expected source metadata and complete world fingerprint. All three external integration tests pass in61.09 seconds. Earlier preliminary test output is not used as the final-source proof.

All compilation/CLI child processes share the serial resource wrapper, MemoryMax4GiB, zero swap, Cargo jobs1 and one test thread. The committed complete patch applies directly to `../inout-stitched-revalidation-2026-10-04/source.tar.gz` and includes the full pinout/checked consumer/export/physical-entry/CLI implementation, plus external tests. Replay `cargo test --offline --test native_physical_inout -- --nocapture --test-threads=1` using the same bounded compiler environment.

The shared terminal currently uses the default physical producer; --grown, --synth, --pins and --evaluation combinations explicitly remain unsupported. Their refusals are not counted as successful support. CLI fallback behavior outside this native inout path still needs complete regression qualification. This is an isolated prototype, not adoption into the current dirty main source tree. Viewer loading/controls/checked X/Z presentation, representative inout variants, intentional caller mismatch controls, transient waveform quality and real Minecraft remain required. All eight broad acceptance rows remain open.
