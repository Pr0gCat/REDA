# 電路生成優化：置中槽位重心排序（2026-09-30）

本輪基準 `d185f12`，保持前端、lowered netlist、閘間距、通道策略及幹線分支強度預算。

## 觀察與根因

`build_floorplan` 的重心排序將短列等比例拉伸到最寬列；後續 X placement 則只是按整數槽位置中，維持固定 14 格閘距。原生七段的最寬列有 12 個閘，4 個輸入的相對槽位實際是 4、5、6、7，排序模型卻使用 1.5、4.5、7.5、10.5。因此重心目標中的線長關係與真正放置關係不一致。

此前在 `864e7ec` 上實驗此模型，方塊雖變少，但最慢穩定時間增至 50 ticks，已撤回並記錄在 `generator-rejected-experiments-2026-09-30.md`。`d185f12` 已移除幹線的全域階梯 reserve，本輪在這個新基準重做相同排序實驗，沒有降低驗收。

## 通解與實驗

排序使用 `position + floor((widest-len)/2)`，與 X placement 的整數置中槽位一致。維持三輪重心掃描、排序 tie-break、固定閘距與奇偶列實際偏移。此排序模型只描述置中槽位；本輪沒有把奇偶列的 2 格偏移加入重心權重。

新排序作為第一個 compact 候選，實體驗證拒絕時使用 `d185f12` 的舊排序及原備選鏈。`compile_legacy` 保留原拉伸排序。產物 metadata 記錄實際排序策略，佈線統計使用同一策略重建。

新模型能減少某些 net spans，但重心排序仍是啟發式，沒有證明對任意電路或全部時序指標更好。下面呈現本輪實際取捨。

## 量測

release；四個案例各檢查全部 16×16 輸入轉換，時間是 simulator game ticks。

| 案例 | 方塊：前 → 後 | 包圍盒體積：前 → 後 | 最慢時間：前 → 後 | 平均時間：前 → 後 |
|---|---:|---:|---:|---:|
| 原生 and4 | 228 → 228 | 3,528 → 3,528 | 28 → 28 | 6.57 → 6.57 |
| Yosys and4 | 214 → 214 | 2,880 → 2,880 | 22 → 22 | 5.72 → 5.72 |
| 原生 seven_segment | 7,136 → 6,372 | 68,460 → 64,548 | 46 → 46 | 32.92 → 35.49 |
| Yosys seven_segment | 8,342 → 7,976 | 160,026 → 157,344 | 66 → 64 | 52.61 → 48.05 |

原生七段方塊減少 10.7%、體積減少 5.7%，最慢时间維持，但**平均时间增加 7.8%**。本輪接受面積與平均時序的取捨，保留原最慢時序門檻，不能宣稱原生時序全面改善。Yosys 七段方塊減少 4.4%、體積減少 1.7%、最慢時間改善 3.0%、平均改善 8.7%。

手寫單段 5,664 → 5,588 格，手寫完整七段 13,488 → 12,898 格；手寫 and4／full_adder 不變。手寫案例有原真值表回歸，但本輪未額外量測其全部 256 種動態轉換時序，不主張它們的時序改善。

三次物理 metrics、世界指紋與全部時序報告一致；歷史七段布局的 metrics 與指紋仍與基準相同；and4 產物不變。原始前測、三次後測、生成時間與實作 SHA-256 在相鄰 JSON，時間不參與候選選擇。被拒絕時會多一次生成／驗證成本。
