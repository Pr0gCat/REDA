# 目前生成器品質不可退步驗收

有效生成器為 0de792e，這輪開始於 e5fdaf1。過去主品質測試的歷史輸出門檻較寬：原生七段燈毛刺允許 109、最差世界允許 46 ticks，已提交生成器則是 85 與 44。因此部分候選會通過歷史門檻，卻仍被人工對照目前基準拒絕。

新增獨立 frozen checkpoint，取自已提交的 consensus 實驗量測及 driver timing baseline，沒有以候選結果生成門檻，也沒有改寫歷史控制。每個案例保持 256 次完整轉換，使用整數總穩定 tick 表示平均時間限制。原生七段目前總穩定時間上限為 8823，原歷史上限 9086 仍保留。

主測試同時要求歷史控制與目前 checkpoint 通過。檢查最差／總世界穩定時間、燈最晚跳變／毛刺／單一輸入毛刺、驅動最晚跳變／毛刺／單一輸入毛刺／最長及總錯值脈衝寬度。世界指紋作為基準來源證據，沒有要求候選必須相同指紋；不使用閘數、方塊數或體積作為驗收。

實際負向驗證重播上一輪 NOR3 私有 Merge 展開候選（原生七段 42 ticks、毛刺 92）：它過去通過舊固定門檻，現在於 `current generator quality regression: glitch_transitions: 92 > 85` 被拒絕。負向原型隨後撤回，没有把失敗原型加入正式測試或生成器。

此變更讓先前人工執行的不可退步要求成為自動測試，不是電路生成品質改善。未來若生成器改善，更新 checkpoint 必須附獨立對照量測，不能用更新 checkpoint 接納退步；歷史控制仍獨立保留。

最終驗證：主品質、額外矩陣及五個見證全部通過；實際四產物的全部 checkpoint 指標與世界指紋逐欄等於目前已提交生成器。生成器程式未改。
