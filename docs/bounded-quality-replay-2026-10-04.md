# Reject proven quality regressions early; preserve zero-budget seed

Refresh selection previously measured every complete candidate history before rejecting worse aggregate, phase or channel quality. The evaluator now stops a rejected candidate after the first completed phase that proves non-dominance. Aggregate sums/maxima and glitch-transition counts cannot decrease; a completed phase's settlement/channel arrivals cannot be repaired by later phases. Only a candidate that completes the original full protocol can return qualification. Candidate order, limits, physical certification, simulation and acceptance thresholds are unchanged.

The unchanged flat-refresh integration caught an existing zero-budget violation: the matrix candidate replaced the seed even when no proposals were requested. HEAD `856dacc` independently reproduces that failure. Matrix consideration now requires a nonzero budget; zero retains the original qualified seed and its exact historical world/quality. The original test and controls are unchanged.

Validation on HEAD plus only the owned selector: six selection checks pass, including complete accepted-profile equality, real arrival/settlement counterexamples, incomplete replay refusal, modified metadata rejection and 16 repeated public outputs (512 phases /32 driver-lamp channels). The final unit build uses release assertions with opt-level0; initial five checks also pass optimized in both worktree and clean source. The unchanged two-test flat-refresh integration passes optimized, retaining its exact zero-budget world, 512-phase waveform and quality caps. Initial failure, original-head reproduction, source manifests and all terminal logs remain in the adjacent directory. The only later source change adds the wide cfg(test) case; reconstructing the optimized-tested file exactly matches its frozen hash.

This repairs the budget contract and removes avoidable replay of proven losing candidates. It does not claim a measured end-to-end compiler speedup or project-wide convergence. Wider-input default adoption, sequential/HDL/game and other eight-item requirements remain open.
