# Isolated direct-leaf composition experiment

No production hooks or default selection change. The original six-input nine-port source is the same source as the prior rejected unconditional torch composition.

Method: output cones with intersecting primary-input supports are grouped. Independent groups use the existing compile_without_rewrite original direct/raw strategy; the existing ExpandedPhysicalCandidate ownership manifest is sealed with the standard library. Worlds are translated eight air cells apart. Root typed identities, explicit output aliases, route branches, delayed owners, observations, and geometry are translated together. No cells or ownership are inferred by scanning the world. Exact emitted-world fingerprints must match the translation union. Caller pins and non-one-to-one leaf manifests are refused.

All source files and Cargo bindings were snapshotted before execution, along with SHA256 producer executable/library hashes and dependency paths. Every run uses the frozen producer executable. The earlier source-key assumption and matrix-adapter attempts failed closed before any whole comparison; their frozen manifests/logs remain in sibling evidence directories.

Leaf controls are the exact root cone netlists, with public root output ordinals carried through. Each two-input group has 32 retained setup/target phases. Each sealed leaf has the exact same world fingerprint and every phase metric as its original raw control. Constants and shared physical aliases are independently observed. These leaf results do not establish whole-default dominance.

Whole control is reda::compile::compile(lower_optimised(native(source))). Its frozen world hash is identical to the previous baseline 4818f3a3af7c2c2f80c973a59e730e5d82697afb6c519b38483e5a9b01cee37f. Both circuits run all 8192 retained phases; all implemented gates and all public driver/lamp channels must be true after every phase. Per-phase settle time, queue work, Boolean occupied-cell events, and each public channel glitch/arrival/pulse metric must not regress. Occupied-cell counts are descriptive only.

Broader shared-support certified composition is outside this experiment and remains incomplete.

## Result: rejected

Both whole circuits passed all 8192 end-phase truth checks. The original public comparator rejected the candidate: 735 phases regressed settle time, 156 queue work, 304 occupied-cell Boolean events, 512 q driver/lamp glitch phases, and 1024 y driver/lamp arrival phases. First phasewise settle violation was retained setup phase index 26: 14→26 ticks.

The stricter implementation comparison extracted actual graphs by linking a standalone exporter to the exact frozen producer library, then required its world hashes to equal the executed worlds. All 15 gates formed a unique bijection by gate kind and recursively mapped ordered input signatures; all nine ordered public bindings, constants, and v/w shared aliases matched. All 122880 gate-phase end-truth checks passed. Nevertheless, implementation waveform comparison also rejected the candidate: g5/g6 each acquired 512 glitch phases, g3 acquired 15 pulse regressions, and n1/n5/g4 had arrival regressions. No unmapped gate was silently excluded.

For from16→to32 target phase 2113, e→f exchange keeps the original OR g5 high with no q transition. The recompiled raw leaf drops g5 at tick2 then restores it at tick4; q driver pulses at ticks6→8 and q lamp at ticks7→12. See the frozen actual-cell trace files. Recompiling a source-matched standalone raw leaf changed arrival balance. Comparing each sealed leaf only with that recompiled leaf proved faithful translation but did not preserve its original whole-circuit behavior. The next guard must use the original whole physical-cone projection or a whole-bound waveform budget before admitting a local replacement.

No production change was made. Broad goal 3 remains incomplete.
