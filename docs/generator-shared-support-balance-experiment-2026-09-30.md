# 共享主要輸入的延遲平衡實驗

基準 b120a38。承接静態最晚到達補償失敗，本輪以拓撲順序計算每個訊號的主要輸入 support 集合，嘗試將平衡限制於重收斂 NOR，避免補償完全獨立的路徑。仍只調整實際端點中既有中繼器，範圍為 delay 1..4；模型及局限與前一輪相同，仍是測試世界原型，未整合正式生成器驗證與來源記錄。

第一版要求所有輸入 support 的交集非空。主品質 1024 次轉換通過，但兩個七段產物都改動 0 個端點，四個產物的世界指紋、時序及毛刺與已提交基準完全相同。and4 的路由分析不支援，保持原樣。這是無效果結果，不是品質改善，已撤回。

為確認是否只是交集條件過嚴，第二版要求任兩個輸入 support 相交，再對該 NOR 使用原有最晚到達補償。原生七段最差世界／燈仍 44 ticks，平均仍 34.46484375，但燈毛刺 85 → 94，驅動端毛刺 105 → 106，因驅動毛刺門檻而失敗。and4 兩種產物不變；候選在原生七段停止，未測其 Yosys 七段與其他回歸。原型也撤回。

相鄰 JSON 保存兩版原型、第一版完整摘要、第二版驅動量測。没有依閘名稱選擇修改，没有放寬任何門檻。

結論：所有路徑共享輸入的條件沒有可執行補償；放寬到任兩路徑共享輸入則仍增加毛刺。主要輸入 support 只能識別結構相關性，不能區分事件方向、控制值及敏感路徑，因此不是延遲補償的充分條件。下一個可檢查方向是對共享輸入在各路徑上的正反相與控制條件做分析；若需改变非隔離粉線端，必须在路由／發射時建立可驗證的隔離端點，不能事後把粉線任意換成中繼器。

最後還原後主品質、額外矩陣與五個見證全部通過。本次提交只有實驗證據，沒有生成器改動。
