# Native feedback and synchronous next-state reset

Native clocked assignments can now read their own register in the next-state expression or enable condition. The existing logic graph already reserves each DFF identity before resolving its data, so removing the elaborator's redundant self-read guards reuses the state boundary. Pure combinational cycle checks remain intact. No new state representation or simulator behavior is introduced.

Source acceptance alone failed the first physical experiment. A two-bit counter with reset and enable exposed four generator defects:

- Ordinary terminal approach cells were absent from sequential placement geometry, leaving different nets competing for one mandatory straight entry. The ordinary placement model now includes that cell.
- A lever immediately beyond an entry could face away from it. Sequential candidate construction now aligns its pin with the existing approach, reusing the existing Design H primary-source handling. Pinned caller terminals remain governed by their existing contract.
- A multi-input NOR's strongly powered support could backfeed a dust terminal, corrupting a public shared net or even an internal net with only one consumer. Sequential graphs, which do not use qualified weak dust runways, now require a diode at these NOR inputs.
- Design H's inverted-clock torch had no reserved upper conductor cell. A route could put a floor above it and receive clock power through that floor. Its physical footprint now reserves the powered cap, as ordinary torch cells already do.

The Yosys comparison initially left a synchronous-reset FF cell unsupported by the JSON bridge. Standard `dffunmap` now decomposes synchronous reset and enable into data logic plus ordinary DFFs. Yosys remains an optional independent frontend.

Stronger placement exclusivity was tested and rejected: two variants retained existing DFF passes but failed counter routing after 188.12 and 177.14 seconds. The new field and projection rule were removed. Applying the new ordinary-terminal rules to combinational graphs also changed an existing coupling control; the final implementation extends only the existing sequential ordinary-terminal path. Existing qualified combinational generation and its frozen evidence are preserved. Raw failed experiments are listed in the JSON manifest.

The physical test covers Native and actual Yosys versions of three literal fixtures: a two-bit modulo-four counter with synchronous reset priority and enable, a three-state FSM with synchronous reset and advance, and a register whose enable reads its old state (`q || en`). Each runs 64 cycles with low, rising, held-high control changes and falling phases: 256 retained phases per case, 1,536 per run. It saves and reloads the litematic, checks zero power-on before the first edge, preserves history and the existing 2,000-tick ceiling and 16-tick clock-torch dwell, and checks public lamps, every implemented gate and five hidden Design H roles. Master/slave repeater locking is checked directly through the existing read-only simulator query.

An independent Python replay derives state from the literal fixture rules, resolves every implemented combinational gate from that state, and replays all gate, public-lamp and hidden-cell events. It also verifies the exact phase protocol and hidden locks. Corruption checks reject wrong clocks, state, internal truth, locks, missing events, protocol changes and altered power-on values. Three complete trace runs are byte-identical; raw SHA256 is `7ba4886c186ab94f890e314bbe76b7b5bfd0587980f50abb013da9c41eafb38e`.

This qualifies the tested next-state subset, not general Verilog arithmetic, asynchronous reset, reset `if/else` statement forms, negative edges or every possible FSM topology. The counter uses explicit bitwise carry rather than an unsupported data `+` expression. Real Minecraft conformance still awaits owner EULA acceptance; these are simulator and loaded-artifact results. The eight-item goal remains active.

Final validation: 25 compiler, 12 DFF source, 6 frontend-selection, 2 existing DFF physical, 1 multiclock physical and 1 feedback physical test pass; the missing-Python CLI covers all three new fixtures in Native and Auto modes. WASM library checking passes. The complete root remains 1,164 passed, 17 failed and 71 ignored, with the same failure names as the parent. The 4,096-family and Native/Yosys seven-segment and 16×7 ROM controls were each regenerated once and preserve every frozen byte. No complete-project passing claim is made.
