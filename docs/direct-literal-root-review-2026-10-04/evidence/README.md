# Direct literal generation prototype

This isolated experiment starts from committed `08733c1ff5cf279084a543390c9146626fb69e80`. It copies the original parameter-hierarchy source from the root qualification. That source has four inputs and eight public output occurrences, computing y = zero-extended a XOR 16. Shared source was never edited, staged or adopted.

The generic classifier evaluates the complete source truth table and recognizes only constant, direct input and inverted input output functions. It does not inspect module names, gate names or function IDs. The qualified experiment boundary remains four/five inputs and one through sixteen outputs. Every input, including unused inputs, remains in its original order and has a physical control. Each public occurrence owns a distinct lamp. Each rail refresh is an actual declared buffer, rather than an omitted private gate. Constants and typed candidate construction reuse the existing torch-row helpers and library.

The first geometry failed retained-history truth: a lamp beside straight dust does not receive power when dust connections point along the rail. The generic repair adds a dust branch toward each lamp. The failed observation and debug world are preserved. Source/expanded physical certification alone was insufficient; the complete physical simulator history caught the defect. No simulator rules or limits changed.

The final original-source experiment compares the existing budget-zero occurrence matrix against the proposed literal circuit over all 512 setup/target phases. Every public driver/lamp and all 285 baseline or 11 candidate actual gate sites are checked against their own implementation truth, independently derived in original source address order. All occupied signal-site events and queue work remain included. Gate counts describe coverage and are not optimization scores.

All public five-metric vectors are non-regressing phase by phase. Every candidate private gate is also compared phase by phase against every baseline gate with the same complete truth vector; all five metrics are non-regressing. Function matching uses truth vectors, not source/internal names. Unmatched baseline functions remain explicitly listed, truth checked, and included in aggregate private/global event totals; no removed gate gets a fabricated observation position.

Measured settle ticks improve from worst 26 to 6 and total 12064 to 2484. Queue work falls from 40502 to 2040. Observed occupied signal-site events fall from 280665 to 5100. Public and private pulse/glitch/last-change metrics have zero pointwise regressions. `final-quality-comparison.json`, both complete correspondence tables and `private-source-correspondence.json` retain the exact comparisons.

Eight generic controls pass 10240 total phases: mixed literals/inverses/constants, sixteen direct aliases, sixteen inverted aliases, and all constants with no used inputs, each at four and five input boundaries. Nonliteral functions decline the candidate family and preserve the previous occurrence world. Source bindings and distinct output occurrence positions are checked.

The separate prototype selector returns the exact budget-zero matrix with zero proposals. Budget one generates and selects exactly one qualified candidate. Budget four still generates exactly that one available candidate and produces the same world and implementation graph. Baseline fingerprint: a62789fb49cc9e0994e949329ab74d7a5142e81e22753f9f11605f08e2b1be66. Selected fingerprint: 9607cdee623ec4678b2d7d8b11e76530dd0af1f3fad007db973861f354e4239f. Budget controls are real executions, not inferred from code.

All final tools execute frozen binaries after `final-source-binary-manifest.json` is written. Every run has its own manifest. Post-run source/binary drift is empty. The original baseline/candidate raw event streams are preserved as gzip JSONL, with all watched sites, expected truth, transition events, queue work and phase indices; both contain exactly 512 phases. Qualification and artifact hashes are retained separately.

`candidate-core.patch` is the minimal proposed generator/comparator prototype. It has not been connected to the default selector. `owned-full-prototype.patch` additionally contains the evidence observer and raw-event logger; the logger is experiment tooling and is not proposed as product behavior. Core method bodies match the qualified full prototype, but the pruned patch itself still requires an independent clean application/build before adoption. Existing default behavior is unchanged.

Actual Minecraft conformance for this new candidate has not yet run. The root's existing original matrix Minecraft result is not evidence for the changed candidate. Native/frontend provenance and CLI/viewer integration also require qualification on the final adopted generator. No gap is marked complete from this prototype alone.
