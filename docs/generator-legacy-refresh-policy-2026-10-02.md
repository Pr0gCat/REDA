# Caller-owned routing refresh reserves

The low-level legacy compatibility control and ordinary generated routing have different refresh invariants. Frozen legacy branch realization reserves repeater strength for total staircase cost; the qualified generated router reserves for the terminal staircase. The typed adapter previously imposed the generated policy on both callers. The adapter now receives the existing `ReservePolicy` explicitly. Strict and seed routing continue to select `LatestLegalCell`; ordinary ordered and negotiated generation continue to select `TerminalStairs`; the independent historical adapter control selects `TotalStairs`.

This changes no physical verifier, simulator, endpoint eligibility, snapshot assertion, or generated default policy. The existing ring-closure test provides the runnable compatibility check. The older climb/torch-merge and remaining root failures still require their own root-cause fixes.

Two rejected experiments remain important. Excluding unary arrival-balance runways did not fix the three initial standalone failures. Although a unary gate has no arrival skew, its runway still serves generated terminal geometry. Exhaustive default comparison found nine slower functions with that exclusion, including after restoring production terminal reserves. The exclusion was completely reverted. Applying historical total-stair reserves globally also did not qualify and was reverted. Combining historical endpoints with historical reserves still failed the climb fixture; that extra policy abstraction was removed.

The clean parent root run has 1161 passing tests, 20 failures, and 71 ignored tests. The accepted change has 1162 passing tests, 19 failures, and the same 71 ignored tests. Only `lay_net_refuses_the_branch_that_closes_a_ring` is repaired; there are no newly failing tests. Both runs exit 101, so integration tests are validated separately and no all-green claim is made.

Validation results and complete control/candidate root logs are recorded in `generator-legacy-refresh-policy-2026-10-02.json` and its compressed artifacts. The rejected family trace is retained separately. Default generated quality is compared against the actual frozen default, not merely an older candidate. No block or volume counts are acceptance criteria. Repeated complete traces must preserve the frozen 4096-family, Native/fresh-Yosys seven-segment, and 16×7 ROM bytes; the existing independent auditors replay public, internal, and landing events.

This is partial progress on project-wide convergence. All eight goal items remain incomplete. There is no real-game conformance claim: the documented local server directories were absent and a permitted socket check found no local listeners on the configured game/RCON ports.
