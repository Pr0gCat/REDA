# Independent standard HDL shared-bus oracle

The frozen SystemVerilog source has two internal tri-state writers and one external writer on the same top-level inout wire. The testbench enumerates all 64 enable/value states and all 4096 ordered transition pairs, recording both settled endpoints. It uses case equality to classify 0, 1, X and Z, and asserts public readback equals the shared bus at every endpoint.

Root downloads the official Ubuntu `iverilog=12.0-2build2` package to `/tmp`, verifies its SHA256 against APT package metadata, and extracts it without installing anything system-wide. The exact compile command is `/tmp/reda-iverilog-20261004/root/usr/bin/iverilog -B /tmp/reda-iverilog-20261004/root/usr/lib/x86_64-linux-gnu/ivl -g2012 -s oracle_tb -o standard-oracle.vvp fixture.sv oracle_tb.sv`; the runtime command is `/tmp/reda-iverilog-20261004/root/usr/bin/vvp standard-oracle.vvp`. Both commands terminate successfully. The complete output and executable/package/source hashes are retained.

All 8192 standard-simulator endpoints match the independently classified active-driver sets and linear Boolean presence/conflict resolver. There are 19 zero, 19 one, 18 conflicting and eight floating states. Checked observation rejects all 26 X/Z states, rather than interpreting them as zero or high. The original mathematical-model `summary.json` and tool-discovery record precede the later isolated simulator preparation; their lack-of-standard-evidence statements remain as historical snapshots. The later `root-standard-oracle-audit.json` and runnable `audit-standard.py` supply the standard HDL evidence.

These are settled source semantics, not REDA frontend, redstone, transient or Minecraft support. No REDA source changes are adopted. The accompanying cross-layer audit identifies the required real shared channel, diode-isolated injection, read tap and explicit external presence/value sidebands. A split-port adapter cannot close this requirement. Read-dependent drive and clocked sampling still need separate semantic and physical qualification.
