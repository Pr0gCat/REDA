# Native legacy HDL forms

The lexer already recognized `reg` and `always`, but the parser rejected them before existing elaboration could apply. This unnecessarily sent ordinary legacy Verilog to Yosys. Supporting those spellings also exposed `seven_segment.v`'s concatenated continuous assignment target, which the single-target elaborator could not represent.

The parser now maps `reg` declarations to the existing variable representation, accepts wildcard `always @*` / `always @(*)` blocks, and sends parenthesized positive-edge `always` blocks through the existing clocked-block parser. Combinational blocks accept one complete blocking assignment or one fully specified case; clocked blocks retain the existing one feed-forward nonblocking assignment and optional enable semantics. Both block and single-statement legacy bodies work. No source text rewriting or preprocessing backend is involved.

Elaboration decomposes continuous concatenated targets, including nested concatenations and slices, from most-significant target to least-significant target. A transient RTL slice reads the matching bits of the original value. Exact width checks, writable-target checks, range validation and existing per-bit driver validation remain mandatory. Debug origins record the original assignment plus passthrough extraction. Scalar assignments retain their existing path. The modern and both legacy full-decoder sources produce exactly the same logical netlist and output map.

Unsupported sensitivity lists and nonblocking combinational assignments are explicitly classified so auto mode can use the existing Yosys fallback. Syntax errors and semantic errors remain fatal. The fallback tests still run real Yosys, now using genuinely unsupported parameter/event-control forms; forced-Yosys coverage remains. The old undriven `reg z` source stays a negative test, now diagnosing the missing driver rather than rejecting the type spelling. Assigned internal/output `reg` declarations have positive truth coverage.

Limits remain explicit: ANSI declarations, existing every-bit driver completeness even for unused internal declarations, one procedural assignment/case per combinational block, existing case completeness rules, one positive-edge clock and existing feed-forward/enable register semantics. General procedural sequencing, non-ANSI declarations, parameters/instances/inout, reset/multiclock/negedge/feedback and broad no-Yosys acceptance remain unfinished. This implements real legacy forms; rejection diagnostics do not count as implementation of the remaining forms. Real Minecraft conformance is still absent.

Root routing failures were independently reproduced and recorded in `reda-completion-routing-audit-2026-10-02.json` with compressed raw logs. Typed legacy request construction applies balancing runways where the frozen reference uses automatic terminals, including vacuously equal-depth unary receivers. Ring refusals therefore charge different branch suffixes, and a pinned-output defect fixture loses its required repeater premise. No routing snapshots, bug counts or physical verifier rules were modified. The next routing repair must separate compatibility from qualified balancing proposals and retain the accepted physical metrics; updating old expectations alone would not establish that contract.
